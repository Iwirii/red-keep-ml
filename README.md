# Красный замок: Аналитика прочности строительной смеси

Учебный ML-проект в рамках дисциплины «Практикум по программированию» (5 семестр). 
Проект выполняется по методологии **CRISP-DM** и направлен на предсказание прочности бетона на сжатие (Concrete Compressive Strength) с использованием элементов лора мира «Игры Престолов».

## Легенда и постановка задачи
Красный замок в Королевской Гавани — одна из главных крепостей Семи Королевств. Его стены должны выдерживать не только годы эксплуатации, но и осады, удары осадных орудий и другие испытания, которые неизбежно выпадают на долю королевской крепости. И конечно же, драконов.

Для строительства замка мейстеры использовали особую строительную смесь. Ее прочность зависит от состава: количества связующего материала, воды, различных минеральных компонентов и заполнителей. Кроме того, материал постепенно набирает прочность с течением времени.

Чтобы убедиться в надежности стен Красного замка, королевские мейстеры провели серию испытаний строительного материала. Для каждого образца они записали его состав и возраст, а затем подвергли образец испытанию на сжатие.

Теперь необходимо по составу смеси и возрасту образца определить, какую нагрузку способен выдержать материал Красного замка.
